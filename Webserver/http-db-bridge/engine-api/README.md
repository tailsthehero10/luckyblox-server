# Archived 2021 Engine API dump

`0.482.0.424268.json` is the Roblox Lua API dump archived for engine build
`0.482.0.424268` on 2021-06-07. It is used by LuckyBlox Studio's Game Engine
API reference for the `2021M` and `CUSTOM-2021M` clients.

Source:
[RobloxAPI/build-archive, version-c2037653e0a446ac](https://github.com/RobloxAPI/build-archive/tree/8af1cd98d719f823f14aa09a5449c580fda71e20/data/production/builds/version-c2037653e0a446ac).
The archive metadata also lists `version-879389fd96a942b1` for the same build;
both archived API dump files have the same Git blob SHA.

The archived dump is a historical engine API schema, not an assertion that all
listed members are accessible to ordinary scripts or supported by this project.
